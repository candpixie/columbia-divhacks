## Problem Statement

Rent and commute are the biggest tradeoff a New Yorker makes, and no tool shows both on one map. StreetEasy shows rent, Google Maps shows commutes, people juggle tabs and guess. With roommates it is worse: three workplaces, three budgets, one lease. And the cheaper apartment is rarely cheaper once you count the hours.

## What Makes This Cool

1. **Roommate group chat (Photon).** Add the bot to the real group chat. Everyone texts where they work and their budget. It replies with the neighborhoods that work for all of you and a map link.
2. **True Cost.** "The $400 cheaper apartment costs you 7 extra hours a week, which is $210 of your time." Rent + fares + commute hours (weekend service and line reliability included) + value of time, side by side for two neighborhoods.

Everything else is quiet info on the neighborhood card.

## Constraints

- ~28 hours, 4 people, judging Sun 12-4pm. Criteria: concept, functionality, wow, UX, community value.
- Demo must be stable: no live routing, no scraping, LLM never computes numbers.
- A judge "will click the second button": every visible control must work.

## Premises (agreed)

1. Commute and rent are the hard filter. Everything else ranks or informs; no opaque blended "livability score".
2. Safety is an optional layer, off by default: per capita, violent felony categories only (NYPD complaint data), never in the score, never red-zoning. Avoids redlining optics at a housing-equity hackathon.
3. No delay prediction. Use published data: weekday vs Saturday schedules (GTFS) and line reliability (MTA wait assessment).
4. Essentials = walking time to nearest grocery, pharmacy, clinic, shown as card lines.

## Recommended Approach

### Ranking (filter, then rank)

- Hard filters: every person's commute <= their max; rent for `beds = people` <= combined budget.
- Rank survivors: `0.35*rent_headroom + 0.25*commute + 0.20*essentials + 0.20*reliability` (each normalized 0-1).
- Safety never enters the score.

### True Cost (per person, per month)

```
fare        = 132 (30-day unlimited) unless route uses express bus / LIRR / ferry (v2: subway only => 132)
hours_week  = 10 commutes/week weekday time (5 round trips) + weekend trips at Saturday times (2 round trips)
hourly_val  = annual_income / 2080   (income from Nessie; default $30/hr if no account)
true_cost   = rent_share + fare + hours_week * 4.33 * hourly_val
```

Comparison card: pick two neighborhoods, show delta rent, delta hours/week, delta true cost. Headline sentence is templated, not LLM.

### Capital One Nessie

Each person may link a Nessie sandbox customer. Income from deposits drives (a) the **40x rule** badge: annual income >= 40 * monthly rent share ("likely approved"), and (b) `hourly_val` in True Cost.

### Architecture

1. **Precompute (Python).** H3 res 8 hexes over NYC.
   - Travel matrices: `matrix_weekday.bin` (8-9am) and `matrix_saturday.bin` (noon). Plan A r5py (Java 21 + OSM). Plan B by 3pm: station graph from GTFS `stop_times` + straight-line walk x1.3 at 5 km/h.
   - Rent: StreetEasy median asking rent by neighborhood -> NTA; Census ACS median gross rent by tract as fallback.
   - Essentials: NYS retail food stores, NYS pharmacies, NYS health facilities -> nearest walking minutes per hex. USDA food access flag if time.
   - Reliability: MTA wait assessment by line -> per-route on-time %.
   - Safety (last): NYPD complaints, violent felonies, per 1,000 residents per NTA.
2. **Shared scoring** `lib/score.ts` + `lib/trueCost.ts`, imported by web and agent.
3. **Web** Next.js on Vercel, MapLibre + deck.gl `H3HexagonLayer`, static data, URL state (`?p=columbia,35,1400&p=fidi,30,1400&day=sat`).
4. **Agent** Bun + `@photon-ai/imessage-kit` on one team Mac. `onGroupMessage` -> Gemini structured output `{workplace (enum of ~60 places), max_minutes, budget}` -> per-chat per-sender memory -> once >= 2 people, score and reply from a template with the map link.

### Data contract

```
public/data/hexes.json      [{ h3, nta, rent:{"1br","2br","3br","4br"}, ess:{grocery,pharmacy,clinic} (walk min), lines:[..], reach30 }]
public/data/matrix_weekday.bin / matrix_saturday.bin   Uint8 N*N, [origin*N+dest], minutes, 255 = unreachable
public/data/places.json     [{ id, name, h3 }]   agent's workplace enum
public/data/ntas.json       { nta: { name, borough, summary, safety_per_1k } }
public/data/reliability.json { route: on_time_pct }
```
